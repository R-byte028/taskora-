# Taskora Judge Demo

## Product pitch
Taskora is a crypto-first freelancer workspace. Freelancers record client work they obtained elsewhere, track delivery, issue payment requests and verify NEAR testnet payments. Taskora is not a job marketplace.

## Four-minute walkthrough
1. **Workspace (30 sec):** Sign in with a prepared demo account. Show the overview, My Jobs, My Payments and Invoices.
2. **Delivery (45 sec):** Open a prepared job. Show milestones, checklist progress, a dated update and attached evidence. Explain that completing work does not automatically mark payment as received.
3. **Payment (45 sec):** Open the payment request and client checkout. Point out the amount, destination and NEAR testnet disclosure. Show the existing verified testnet payment record; do not make another transfer for the demo.
4. **Verification (45 sec):** Explain that the server verifies network, final execution, signer, receiver, native transfer action, exact amount and duplicate use before recording payment. Mention 18 mock regression tests and 7 synthetic negative-path tests.
5. **Link security (45 sec):** Re-copy an active link, revoke a separate test link, then open the revoked URL and show “Payment request unavailable”. Explain owner-only recovery of active, unexpired links.
6. **Close (30 sec):** Reiterate the work-to-payment workflow and state that this release is NEAR testnet only.

## Recording checklist
- Use a prepared demo account and clean browser window.
- Close unrelated tabs and hide notifications.
- Keep personal client details and account information out of frame.
- Never show credentials, API keys, service-role keys or wallet recovery phrases.
- Reuse the existing verified testnet payment; do not send a new payment.
- Keep the NEAR testnet-only boundary visible and say it aloud.

## Do not claim
- Mainnet, USDC or real-fund settlement support.
- That Taskora is a job marketplace.
- That the Assistant is live AI; AI Gateway setup is deferred.
- That job completion automatically means payment has been received.
